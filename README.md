## 📖 Tentang Proyek (About the Project)

**Mentari Bersastra** adalah platform web literasi modern yang dirancang sebagai oase dan ruang publikasi bagi para penikmat aksara, penyair, penulis cerita pendek, esais kebudayaan, dan pegiat literasi nusantara. 

Di tengah derasnya arus informasi instan di era digital, Mentari Bersastra hadir membawa napas kontemplasi yang tenang dengan sentuhan tipografi sastra yang hangat, estetika modern efek kaca (*glassmorphism*), dan komitmen kuat terhadap orisinalitas karya sastra Indonesia.

### 🌟 Nilai Utama Mentari Bersastra
1. **Kejernihan Nurani & Estetika Rasa:** Menyajikan tulisan yang mengasah kepekaan batin dan memperkaya khazanah batin manusia.
2. **Kemandirian & Keadilan Kurasi:** Memberikan panggung terbuka bagi penulis pemula maupun sastrawan berpengalaman secara bebas biaya (100% gratis).
3. **Penghormatan Hak Cipta:** Menjaga hak moral dan hak ekonomi para penulis sesuai amanat UU No. 28 Tahun 2014 tentang Hak Cipta.
4. **Keamanan & Privasi Pembaca:** Menghormati kerahasiaan data pembaca berlandaskan UU No. 27 Tahun 2022 tentang Pelindungan Data Pribadi (UU PDP).

## ✨ Fitur-Fitur Unggulan (Key Features)

### 🎨 1. Desain Modern Efek Kaca (Glassmorphism Aesthetic)
- **Header Kaca Translusen (`.glass-navbar`):** Menggunakan efek *frosted blur* (`backdrop-filter: blur(20px)`), tata letak bersih tanpa menu ganda, dan kolom pencarian dinamis (`.glass-input`).
- **Footer Kaca Hangat (`.glass-footer`):** Berpadu harmonis dengan palet latar kertas krem (`#fbf8f2`), memuat kanal komunitas, navigasi ruang baca, dan komitmen redaksi.
- **Kartu Artikel Interaktif (`.glass-card`):** Memberikan kenyamanan membaca dengan efek elevasi halus dan tipografi serif Merriweather yang ramah di mata.

### 🧭 2. Menu Hamburger & Panel Laci Geser (*Offcanvas Drawer*)
- Tombol hamburger bergaya kaca (`.glass-hamburger-btn`) yang responsif di desktop maupun ponsel.
- Menyediakan akses instan ke:
  - Pencarian cepat artikel dan puisi.
  - Profil pengguna terverifikasi / status login.
  - Seluruh rubrik kategori sastra (penyaringan langsung ke artikel).
  - Seluruh dokumen kebijakan dan informasi literasi.

### 📚 3. Halaman Informasi & Komitmen Redaksi Lengkap
Platform ini telah dilengkapi 5 halaman informasi resmi yang dimuat langsung oleh footer dan menu hamburger:
- **`#/tentang` (Tentang Mentari Bersastra):** Visi, misi, rubrik utama, dan perkenalan dewan kurator.
- **`#/kirim-karya` (Panduan Kirim Karya & Kurasi):** Kriteria naskah puisi, cerpen, esai, dan resensi buku, format pengiriman, serta 3 tahapan alur kurasi naskah.
- **`#/hak-cipta` (Hak Cipta Penulis & Karya):** Jaminan hak kepemilikan seutuhnya pada penulis, lisensi publikasi digital non-eksklusif, dan sikap *zero tolerance* terhadap plagiarisme.
- **`#/kebijakan-privasi` (Kebijakan Privasi Pembaca):** Transparansi pengelolaan data akun sesuai regulasi UU PDP.
- **`#/kode-etik` (Kode Etik Kurasi Literasi):** Standar integritas, kepekaan budaya nusantara, dan independensi penilaian.

### ✍️ 4. Portal Pengguna & Manajemen Redaksi (CMS)
- **Autentikasi Supabase:** Registrasi akun baru, masuk akun dengan email dan sandi, serta integrasi sesi cloud yang aman.
- **Dashboard Redaksi:** Statistik karya, penambahan tulisan baru dengan dukungan format Markdown, sunting artikel, pengaturan status terbit (*publish/draft*), dan manajemen kategori.
- **Pengaturan Profil Akun:** Pengelolaan nama pena, biografi literasi, surel, tautan portofolio, dan foto avatar.
- **Ruang Apresiasi Pembaca:** Kolom komentar interaktif pada setiap tulisan yang terbit.

## 🛠️ Tumpukan Teknologi (Tech Stack)

## ⚙️ Konfigurasi Environment (`.env`)

Untuk menghubungkan Mentari Bersastra dengan layanan Supabase Cloud Anda, konfigurasikan berkas `.env` (atau isi pada *Environment Variables* di Dashboard Vercel):

```env
# Kredensial Supabase Cloud
VITE_SUPABASE_URL=https://proyek-anda.supabase.co
VITE_SUPABASE_ANON_KEY=eyJh...kunci-anon-anda...
```

> **Catatan Ketahanan (Offline/Fallback):**  
> Jika kredensial Supabase belum diisi atau sedang terjadi kendala jaringan, platform tetap dapat beroperasi secara normal menggunakan *mock data* literasi dan penyimpanan *local storage* terintegrasi.

## 🚀 Menjalankan Proyek Secara Lokal

Bagi pengembang yang ingin menjalankan proyek ini di lingkungan lokal:

1. **Klon Repositori:**
   ```bash
   git clone https://github.com/kiranakirani347-ux/Mentari-Bersastra.git
   cd Mentari-Bersastra
   ```

2. **Pasang Dependensi:**
   ```bash
   npm install
   ```

3. **Jalankan Server Pengembang:**
   ```bash
   npm run dev
   ```
   Aplikasi akan aktif di `http://localhost:3000`.

4. **Kompilasi Siap Produksi (*Build*):**
   ```bash
   npm run build
   ```

## ☁️ Penerapan ke Vercel (Deployment)

Proyek ini telah dikonfigurasi secara optimal untuk penerapan di [Vercel](https://vercel.com/):
1. Repositori dihubungkan langsung dengan proyek Vercel Anda.
2. Setiap kali ada perubahan yang di-*push* ke branch `main`, Vercel akan otomatis melakukan proses *build* dan *deploy*.
3. Berkas `vercel.json` sudah menyertakan konfigurasi *URL rewriting* sehingga perutean halaman (*hash/route*) tetap berfungsi lancar tanpa pesan error 404 saat halaman dimuat ulang.

## ⚖️ Hak Cipta dan Etika Sastra

- Seluruh karya tulisan (puisi, prosa, cerpen, esai, dan resensi) yang diterbitkan di Mentari Bersastra adalah hak cipta moral dan ekonomi milik masing-masing **Penulis/Penyair**.
- Mentari Bersastra memegang hak penyiaran non-eksklusif secara digital.
